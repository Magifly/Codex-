# 两台设备协作

1. 每台设备分别安装、登录 Codex 并配置 GitHub 访问权限。
2. 分别克隆同一个工作仓库，在各自本机目录中工作。
3. 开始任务前检查本地改动和远端更新，为任务创建独立分支。
4. 阶段性完成后执行相关验证，更新交接文档，检查敏感信息，再提交并推送。
5. 另一台设备获取更新，切换到交接分支并继续；原设备停止修改该任务分支。
6. 同时工作时使用不同分支，尽量处理不同模块，先后整合到 main。

GitHub 同步的是已推送的文件；聊天记录、登录状态和正在执行的任务不通过 Git 仓库转移。
不要使用网盘同步同一份 Git 工作目录。不要把 Codex 登录缓存或真实 .env 提交到仓库。
