# Codex 多设备协作实验

记录个人在两台设备上使用 Codex 的实践，分享通用说明、脱敏示例和可复用模板。

## 工作方式
两台设备分别安装并登录 Codex，各自克隆项目，通过 GitHub 共享已提交的代码和文档。

- 接力同一任务：原设备提交并推送，另一台设备获取更新并阅读交接记录。
- 同时处理不同任务：每个任务使用独立分支，完成验证后合并。
- 登录凭据、真实密钥和本机运行状态保留在各自设备上。

## 目录
- docs/：多设备操作说明。
- examples/：以后添加的虚构数据示例。
- templates/：可复用的脱敏交接模板。

## 内容范围
本仓库仅保存适合公开的内容，不保存私人工作区副本、个人数据或凭据。
个人工作在单独的私有仓库中进行；经检查后才将可公开内容单独发布到这里。

本仓库不是 OpenAI 官方项目。
